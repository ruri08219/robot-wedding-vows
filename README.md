One line of wedding vows for a robot couple — a promise to stay plugged in through every firmware update and dead battery, with the joke landing in the last few words. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty ($2 in USDC).

## Run it

```bash
python3 main.py
```

This writes the vow (a single line, 136 characters) to `/output/entry.txt`.
